---
name: Arabic typography
description: Project-wide rule for connected Arabic letterforms in CLUNY interfaces and printed output.
---

Arabic text must use normal letter spacing so connected letters are not separated by tracking or added character spacing. Apply this across screens, dialogs, and printed content.

**Why:** The user wants Arabic text to remain visually connected throughout the system.

**How to apply:** Check Arabic labels, headings, utility classes, inline styles, and generated print HTML whenever adding or changing UI. Remove character tracking from Arabic strings.
